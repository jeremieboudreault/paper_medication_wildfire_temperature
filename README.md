Effects of high temperature and wildfire smoke on prescription
medication claims across Canada 🌡️🔥💊
================================================================================
    
These are the scripts to reproduce the analyses presented in *Effects of high temperature and wildfire smoke on prescription
medication claims across Canada*, submitted for publication.

- By [Jérémie Boudreault](https://jeremieboudreault.github.io/), Lea Mayer, Ghazaleh Allameh, Cirhan Truswell, Dale Perry, Scott Weichenthal and Jill Baumgartner

---

### Data

We cannot share the claims data that was provided by a Canadian private insurer.

However, we included temperature, PM2.5 and wildfire smoke data in the `data_sample.csv` file for 10 randomly selected FSAs across Canada. The `MEMBERS` column was set to 1000 for each FSA, and the number of claims was simulated with Poisson(λ=200)) so that all the code than be ran.

---


### Script

The `main.R` script coutains all informations to run the models presented in the paper.
